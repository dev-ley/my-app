# Meu Projeto em Next.js e Tailwind CSS

Este repositório contém o código-fonte de um site responsivo desenvolvido com **Next.js** e **Tailwind CSS**, projetado para oferecer uma experiência rápida, acessível e moderna.

## 🛠️ Tecnologias Utilizadas

- **Next.js**: Framework React para renderização server-side e construção de aplicações web otimizadas.
- **Tailwind CSS**: Framework de CSS utilitário para criação de designs modernos e responsivos.

## 📂 Estrutura do Projeto

- **`/pages`**: Contém as páginas da aplicação.
- **`/components`**: Componentes reutilizáveis utilizados no projeto.
- **`/styles`**: Estilos globais e configurações do Tailwind CSS.
- **`/public`**: Arquivos estáticos, como imagens e ícones.
